# Sideline Stats V0.3 — Game-Day Test Build

## New in V0.3
- Delete individual saved games without deleting the roster/team.
- Reset All Data in Edit Team > Data Management.
  - Requires a warning and typing RESET.
- Existing V0.2 browser data automatically migrates into V0.3.
- Rebuilt Share screen:
  - Team-color branding
  - Scoreboard
  - Game leaders
  - Offense stat tables
  - Defense stat table
- "Share Branded Image" creates a PNG game summary.
  - On supported iPhones/Safari it uses the native Share sheet.
  - Otherwise it downloads/saves the image.
- Copy Text remains available as a fallback.
