# Sideline Stats V1.6 — Snap Tracker

## Snap tracker behavior
- Every player defaults to **checked / on the field**.
- Before each play, uncheck only the boys who are on the sideline.
- Tap **Record Snap**.
- Every checked player receives one snap for that game.
- Immediately after recording, the entire roster automatically resets to **checked** for the next play.

## Per-game proof
Each game stores its own snap records, including which players were counted on each snap.

The Snap screen shows each player's snap count for the active game.

## Convenience
- Check All button
- On-field count
- Total player-snap count
