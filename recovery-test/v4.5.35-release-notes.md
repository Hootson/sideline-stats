# Sideline Stats Gridiron V4.5.35

Follow-up fixes after V4.5.34:

- Restores spoken called-play number extraction for phrases such as “we called play number five” and “the play called was number 10”.
- Adds regression coverage for quarter-aware field coordinate round trips so visual field flips cannot redefine canonical yard-line storage.
- Adds phone-safe vertical scrolling for long player grids inside clarification modals.
- Bumps PWA/service-worker cache version so clients receive the follow-up assets.

Canonical field storage remains team-relative: 0 is our goal line, 50 midfield, 100 opponent goal line. Quarter orientation changes only the physical display position.
